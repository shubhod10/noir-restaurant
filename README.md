# NOIR — Restaurant Landing Page

A premium restaurant landing page concept built with React and Vite.

## Live Demo

[View Live Demo](PASTE_YOUR_VERCEL_URL_HERE)

## Features

- Premium luxury restaurant design
- Cursor-responsive hero section
- Interactive menu cards
- Dish image hover effects
- About and contact sections
- Responsive mobile layout
- Clickable phone and email links
- Social media footer links

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Responsive Design

## Run Locally

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```
